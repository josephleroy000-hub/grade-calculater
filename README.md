# Student Grade Calculator 🎓

## Problem Statement
Create a Python program that:
- Accepts student names and their marks in 5 subjects.
- Calculates total marks and percentage.
- Assigns grades based on percentage:
  - A: >= 85
  - B: 70–84
  - C: 50–69
  - F: < 50
- Displays the results in a neat table format.

## Task for Contributor
The starter code is incomplete. Your task is to:
- Complete the missing functions in `grade_calculator.py`.
- Make sure the program runs successfully.
- Write at least 3 test cases in `test_grade_calculator.py`.
